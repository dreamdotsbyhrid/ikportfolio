# Indrajith K — Professional Portfolio

A responsive, dependency-free portfolio for GitHub Pages. Built with HTML, CSS and JavaScript, using the supplied résumé and visual references..

## Files
- `index.html`: page content and contact links.
- `styles.css`: colors, layout, and responsive styles.
- `script.js`: mobile menu and copyright year.
- `assets/`: optimized supplied photos, favicon, and downloadable original résumé.
- `portfolio.code-workspace`: VS Code workspace.
- `.nojekyll`: disables Jekyll processing for this static site.

## Edit your content
Update text directly in `index.html`. Change theme colors in the `:root` block in `styles.css`. Replace photos in `assets/` while preserving names, or update the corresponding image paths. Replace `assets/Indrajith-K-Resume.pdf` to update the résumé. Check the MBA status, role dates, phone, and email before publishing. The résumé's qualification names and dates are retained as provided.

The contact form opens a prefilled email draft using the visitor’s email app; it does not submit or store messages. Email, phone and LinkedIn links are also available. The work photos are supplied images; no project results or sales metrics have been invented. The original downloadable résumé includes personal details supplied in the source PDF; review it before making the repository public. The webpage itself omits date of birth, passport details, marital status, and full home address.
